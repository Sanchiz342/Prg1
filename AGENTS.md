Agent Instructions

Project Structure

This repository contains multiple independent mini-projects.

Rules for creating mini-projects

When creating a new mini-project:

1. Create a separate dedicated folder for the new mini-project.
2. The new mini-project must be fully independent from the other mini-projects.
3. Do not modify, delete, rename, or reorganize files belonging to other mini-projects.
4. Do not reuse or overwrite files from another mini-project unless explicitly requested.
5. Keep all files, source code, resources, and configuration specific to the new mini-project inside its own folder whenever possible.
6. Changes to one mini-project must not affect the functionality or structure of other mini-projects.
7. Before making changes, inspect the repository structure and identify which folders belong to existing mini-projects.
8. If it is unclear where the new mini-project should be created or whether a change would affect another project, ask for clarification before proceeding.

Core principle

Every mini-project must be isolated in its own folder. Treat existing mini-projects as independent and do not modify them when working on a new one.
